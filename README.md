# Varun Resume · CV · Life Site

A clean, responsive single-page site to showcase resume, CV, life experiences, skills, certifications, projects, and a photo gallery.

## Quick Start

1. Replace placeholder images in `assets/`:
   - `profile.jpg` — your portrait
   - `hero.jpg` — wide background image
   - Add gallery photos like `sample1.jpg`, `sample2.jpg` …

2. Put your PDFs in `assets/`:
   - `Varun_Chaubey_Resume.pdf`
   - `Varun_Chaubey_CV.pdf`

3. Edit content in `index.html`:
   - Update **About**, **Experience**, **Projects**, **Certifications**, **Contact**
   - Update Open Graph and JSON-LD (SEO)

4. Open `index.html` in your browser.

## Deploy

- **GitHub Pages**: push to a repo and enable Pages
- **Netlify**: drag-and-drop this folder into Netlify
- **Vercel**: `vercel` deploy as static site

## Tips

- Add certification verify links to each card.
- Add more sections by duplicating `.section` blocks.
- To change theme default to light, add `class="light"` to `<html>` element.
